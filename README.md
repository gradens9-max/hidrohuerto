# HidroHuerto

App web en Next.js 16 sobre cultivos hidropónicos: catálogo con buscador y filtros, sistemas y beneficios.

## Instalación
npm install

## Uso
1. Copia `.env.example` a `.env.local`.
2. Ejecuta `npm run dev` y abre http://localhost:3000

## Tecnologías
Next.js 16 (App Router), TypeScript, Tailwind CSS, Route Handlers (`/api/cultivos`, `/api/sistemas`).
